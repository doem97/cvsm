CVSM v0.1.0 是预发布版本。它已经用来开发它自己，1.0 之前接口仍可能变化。

## 预发布意味着什么

- [保持不变的接口](/cvsm/zh-cn/reference/interfaces/)是对接入方的实现而言的；1.0 之前，CVSM 自己仍可能改它们。
- 每个版本都打 tag，第一个是 `v0.1.0`。在接入提交里记下你复制的 CVSM 版本或 commit，以后好对照 CVSM 的改动。
- 本文档站发布在 GitHub Pages 上。
