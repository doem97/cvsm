CVSM 处于预发布阶段。它已经用来开发它自己，但在第一个正式版之前，接口仍可能变化。

## 预发布意味着什么

- [保持不变的接口](/cvsm/zh-cn/reference/interfaces/)是对接入方的实现而言的；在第一个正式版之前，CVSM 自己仍可能改它们。
- 截至 2026-10-18，还没有 tag 或带版本号的发布。在接入提交里记下你复制的 CVSM commit，以后好对照 CVSM 的改动。
- 本文档站随第一个正式版发布在 GitHub Pages 上。
