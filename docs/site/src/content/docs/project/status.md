CVSM v0.1.0 is a pre-release. CVSM runs its own development, and its interfaces may still change before 1.0.

## What pre-release means

- The [interfaces that stay fixed](/cvsm/reference/interfaces/) are fixed for adopters' implementations, but CVSM itself may still change them before 1.0.
- Releases are tagged; `v0.1.0` is the first. Record the CVSM version or commit you copied in your adoption commit, so you can compare later CVSM changes against it.
- This docs site is published on GitHub Pages.
