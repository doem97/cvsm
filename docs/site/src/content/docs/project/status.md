CVSM is a pre-release. It runs its own development, and its interfaces may still change before the first release.

## What pre-release means

- The [interfaces that stay fixed](/cvsm/reference/interfaces/) are fixed for adopters' implementations, but CVSM itself may still change them before the first release.
- As of 2026-10-18 there are no tags or versioned releases. Record the CVSM commit you copied in your adoption commit, so you can compare later CVSM changes against it.
- This docs site is published on GitHub Pages with the first release.
